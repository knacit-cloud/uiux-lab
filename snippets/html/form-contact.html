問い合わせフォーム

空のまま送信 / 不正なメールアドレス / 全角入力 を試してください。

全角で入力しても自動で半角に直します。

ハイフンはあってもなくても構いません。

所要3分・費用はかかりません・送信後、確認メールが届きます

設計メモ

  • 項目は5つ。部署・役職・住所・従業員数は聞いていない
  • 電話番号は任意（必須にすると「電話が来る」と思われて離脱する）
  • プレースホルダをラベル代わりにしない。ラベルは入力欄の上
  • 「必須」と書く（* だけに頼らない）
  • type / inputmode / autocomplete を全部指定 → モバイルで正しいキーボードが出る
  • 入力欄の font-size は 16px 以上（iOS の自動ズーム防止）
  • エラーは該当欄の直下にインライン表示。aria-describedby で紐付け
  • 入力中はエラーを出さない。blur で検証、直ったら即消す
  • 送信時は最初のエラー欄にフォーカスを移す
  • 全角入力は弾かずに自動で半角へ正規化（ポステルの法則）
  • ペーストを妨害しない
  • 失敗しても入力内容を消さない

data-ajax を外すと通常の POST 送信になります（JS なしでも動く）。
