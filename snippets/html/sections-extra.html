設計メモ
  • モバイルでは1カラムに落とす。小さい画面で面積差は表現できない

Layout 5-B

料金比較表（横スクロール）

プランが4つ以上、または機能差が細かいとき。 モバイルで縦積みに崩さない（比較できなくなる）。

プラン別の料金と機能の比較
項目 お試し 標準（おすすめ） 拡張
月額（税抜） 0 円15,000 円35,000 円
利用人数 1 名5 名20 名
見積の作成 ✓ 1件のみ ✓ 無制限 ✓ 無制限
単価表の取り込み — ✓ ✓
最低契約期間 なしなしなし
設計メモ
  • 縦積みに崩さない。比較が目的なので、横スクロールが正しい
  • margin-inline: -1.5rem ＋ padding-inline で 画面端までスクロールさせる。見切れが「まだ続く」の合図
  • スクロール領域には tabindex="0" ＋ role="region" ＋ aria-label が必要。これがないとキーボードで横スクロールできない
  • <th scope="col"> / scope="row" を正しく付ける
  • 数値列に tabular-nums。桁が揃わないと比較できない
  • ✓ / — は記号だけだと読み上げられない。 aria-label で意味を付ける（色だけで伝えない）

Responsive

モバイル追従CTA

幅を 768px 未満にして、このセクションより下へスクロールすると 画面下部に出ます。fold 内では出しません（ヒーローのCTAと重複するため）。

見積を1件、無料で作らせてください
設計メモ
  • fold 内では出さない。ヒーローのCTAと重複する。 基準要素を IntersectionObserver で監視する
  • env(safe-area-inset-bottom) でホームバーを避ける。 viewport-fit=cover が <meta> に必要 （書かないと env() が 0 になる）
  • @media (min-width: 768px) でデスクトップには出さない
  • 高さを抑える。画面を食う
  • フッターのCTAと重なるなら、フッター到達で隠す
  • IntersectionObserver 非対応なら常時表示にフォールバック

↑ ここまでスクロールすると追従CTAが出ます（幅 768px 未満のとき）。
