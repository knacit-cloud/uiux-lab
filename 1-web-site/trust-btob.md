# 信頼の設計（BtoB）

BtoC は「欲しいか」で決まる。**BtoB は「失敗しないか」で決まる。**
担当者は社内で説明責任を負う。だから BtoB サイトの仕事は、
魅力を伝えることよりも**「これを選んで大丈夫だ」と言える材料を渡すこと**。

特に**小規模・新しい会社**ほど、ここを設計しないと勝てない。

---

## 信頼を落とす要素（まず潰す）

魅力を足す前に、これを消す。減点の方が効く。

- [ ] **会社情報がない／探しにくい**（所在地・代表者名・設立年）
- [ ] **顔が見えない**（BtoB の少人数事業では致命的）
- [ ] 連絡先が個人の Gmail
- [ ] 料金が一切書いていない
- [ ] 誤字・リンク切れ・画像切れ
- [ ] 「最新情報」が数年前で止まっている
- [ ] SSL でない、表示が遅い
- [ ] ストックフォトだらけ
- [ ] 抽象的な言葉ばかりで、何をする会社か分からない
- [ ] 実態と釣り合わない誇大な表現（「業界No.1」「豊富な実績」で中身なし）

**最後の項目が特に重要。** 実績のない会社が実績を匂わせると、
バレた瞬間に他の全ての記述の信憑性が消える。

---

## 信頼を作る要素（強い順）

### 1. 第三者の証言
導入企業のロゴ、顧客の声（実名・所属・顔写真つきが最強）、事例、メディア掲載。
**匿名の「A社様」は効果が大幅に落ちる。**

出せるものがないときは、**無理に作らない。** 空欄にして他で勝負する方がまだいい。

### 2. 具体的な数字
「業務時間を削減」ではなく「受発注の処理時間を月42時間から18時間に」。
**桁が細かいほど本当らしい。** 丸めた数字は嘘に見える。

### 3. 顔と名前
代表の顔写真・経歴・なぜこの事業をやるのか。
小規模事業では**「誰がやるか」が商品そのもの**。ここを隠す理由がない。

### 4. プロセスの透明性
申し込んだ後、何が・いつ・どの順で起きるか。
**高単価な無形サービスほど、ここの不安が最大の障壁。**

```
無料診断（3分の入力）
  ↓ 3営業日以内
診断レポートをお送りします
  ↓ ご希望があれば
30分のオンライン面談
  ↓
ご提案・お見積り
  ↓ ご検討ください
契約 → 伴走開始
```

**「いつでも断れる」ことを明示する。** これが一番効く不安除去。

### 5. 料金の開示
BtoB で料金非公開は、比較検討の土俵から降りるのと同じ。
金額が確定できないなら **「◯万円/月〜」と下限を出し、何で変動するかを書く**。

### 6. できないことを書く
**対応範囲外を明記すると、対応範囲内の記述の信憑性が上がる。**
「私たちは◯◯はやりません」は、誠実さの最も安いシグナル。

### 7. 実在性の証拠
所在地（市区町村まで）、法人番号、設立年、事業内容。
BtoB の担当者は**本当に調べる**。

## 実績がないときに、何を差別化として書けるか

⚠️ **この節は通し試作（`trials/2026-08-01-zoen/LOG.md` F-2）で追加した。**
「背負えないことを言わない」という禁止だけがあって、
**証拠がないときに何を書けるかの積極的な指針がなかった。**

創業直後・実績ゼロで差別化を書こうとすると、
証拠がないのに強く言いたくなって禁止事項に触れる。
**その回避策ではなく、実績がなくても成立する差別化の型を使う。**

### 型①：範囲を狭める ★最も効く

「他社よりうまい」ではなく「**扱う範囲を絞った**」と書く。
これは実績がなくても**今日から真実**にできる。

```
✕ 高品質な見積作成支援             ← 証拠が要る
○ 造園・外構だけを扱います。
  樹木・石材・土工の単価表を最初から持っています。
  （汎用の見積ソフトは、この単価表を自分で作るところから始まります）
```

**狭めることは、能力の主張ではなく事実の宣言。** だから背負える。
そして相手にとっては「自分の業種を分かっている」という具体的な安心になる。

### 型②：やらないことを明示する

対応範囲外を書くと、**対応範囲内の記述の信憑性が上がる。**

```
○ 一般土木・建築は扱いません。積算の考え方が違うためです。
○ 導入後の運用代行はしません。使うのは御社です。
```

### 型③：プロセスを全部見せる

結果を約束できないなら、**手順を約束する。**
「何を・いつ・どの順でやるか」は実績ゼロでも書ける。
→ `1-web-site/layout-patterns.md` の「流れ」セクション

### 型④：個人の経歴を根拠にする

**会社の実績はなくても、人の実績はある。**

```
○ 造園会社で7年、見積と現場管理をしていました。
```

会社設立が2026年でも、この7年は嘘ではない。
BtoBの小規模事業では「誰がやるか」が商品そのもの。

### 型⑤：リスクを自分が持つ

相手にリスクを負わせないことが、そのまま差別化になる。

```
○ 1件目は無料で作ります
○ 最低契約期間はありません
○ やめても費用はかかりません
○ 合わなければそこで終わりで構いません
```

**実績がある会社ほど、この条件を出さない。** だから逆に効く。

### 型⑥：実績がないことを、自分から先に書く

隠すと調べられて失う。**先に言えば誠実さになる。**

```
○ 正直に書きます。まだ3社にしか使っていただいていません。
  だからこそ、1件目を無料で作らせてください。
```

**ただし「だから安い」「だから頑張ります」で終わらせない。**
必ず**相手の利益になる条件**（無料・解約自由）とセットにする。

---

### やってはいけない代替

| ✕ | なぜダメか |
|---|---|
| 「創業まもないベンチャー」を売りにする | 相手の利益にならない |
| 「大手にはできない小回り」 | 全社が言う。中身がない |
| 実績の代わりに理念を長く書く | 読まれない。判断材料にならない |
| 匿名の「A社様の事例」 | 実績があるように見せている＝虚偽に近い |

## 言葉の作法

### 背負えないことを言わない
- 「専門家」は、その分野の専門メンバーが実在するときだけ使う
- 「追加料金なし」は、絶対にそうできるときだけ約束する
- 「豊富な実績」は、示せる実績があるときだけ

言い換えの例：
| 背負えない表現 | 言い換え |
|---|---|
| 専門家が診断します | 外からの視点で見つけます |
| 豊富な実績 | （具体的な事例を1つ出す。なければ書かない） |
| 業界最安値 | 月2万円から始められます |
| 完全サポート | 月◯回のミーティングで伴走します |

### 能動態・二人称
「業務改善が実現されます」ではなく「◯◯の作業が要らなくなります」。

### 専門用語を訳す
DX、アジャイル、ソリューション、リスキリング。
**相手が日常的に使わない語を、説明なしに使わない。**
「現場の人が言っている言葉」で書く（Nielsen 第2原則）。

## FAQ の使い方

FAQ は「よくある質問」ではなく、**購入直前の懸念を潰す場所**。

入れるべき質問は、実際に商談で聞かれること：
- いくらかかるのか／何で変動するのか
- 途中でやめられるのか
- どのくらいの期間で成果が出るのか
- 自社の業種・規模でも対応できるのか
- 何を準備すればいいのか
- 情報の取り扱いはどうなるのか

入れなくていい質問：
- 「御社の強みは何ですか」（本文で言うこと）
- 答えが「ケースバイケースです」で終わるもの（不安が増える）

実装：`<details>` / `<summary>` で組むとJS不要・アクセシブル。
ただし**検索エンジンに読ませたいなら、閉じていても DOM には存在させる**（`display:none` にしない）。
構造化データ `FAQPage` を入れると検索結果に出る可能性がある。
