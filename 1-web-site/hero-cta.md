# ヒーローと CTA

ページで最も投資すべき2箇所。ここが弱いと下の全部が読まれない。

## ヒーロー

### 10秒で答えること

⚠️ 出典：[NN/g — Homepage Design: 5 Fundamental Principles](https://www.nngroup.com/articles/homepage-design-principles/)（本文照合済）

ユーザーは 10–20 秒で離脱する。**明確な価値提案があるページだけが、それ以上引き止められる。**

ヒーローが答えるべきは3つだけ：

1. **これは何か**（誰の、どんな課題を扱うのか）
2. **なぜここか**（他と何が違うのか）
3. **次に何をすればいいか**（CTA）

### 構成要素

```
┌──────────────────────────────────┐
│  [ロゴ]              [ナビ]  [主要CTA] │
├──────────────────────────────────┤
│                                  │
│   見出し（価値提案）                  │  ← 一番大きい。1つだけ
│   サブコピー（補足・具体化）            │  ← 見出しの言い換えにしない
│                                  │
│   [主要CTA]   副次リンク →            │  ← 主要は1つ
│                                  │
│   軽い信頼要素（実績数字・導入企業）      │  ← あると強い
│                                  │
│                    ┈┈次セクションの見切れ┈┈ │  ← false floor 対策
└──────────────────────────────────┘
```

### 見出しの書き方

**悪い例と良い例：**

| ✕ | ○ |
|---|---|
| 「未来を、共に創る。」 | 「現場の非効率を、外からの視点で見つけます」 |
| 「DXソリューション」 | 「何から手をつけるべきか、無料で診断します」 |
| 「私たちについて」 | 「◯◯業の受発注業務を、3ヶ月で半分の時間に」 |

原則：
- **抽象的なブランドコピーを見出しにしない。** ユーザーは詩を読みに来ていない
- **主語をユーザーにする。** 「私たちは〜を提供します」ではなく「あなたの〜が〜になります」
- **具体的な名詞と数字を入れる。** 業種・課題・期間・数値
- サブコピーは見出しの**言い換えではなく補完**。見出しで言えなかったことを言う

### 画像・ビジュアル

- **汎用ストックフォトを使わない。** 握手する外国人のビジネスマンは信頼を下げる
  （NN/g も「ブランドを真正に表すイメージを使え」と明示）
- 使えるもの：実際の画面、実際の人、実際の成果物、抽象的な図解
- 何もなければ**タイポグラフィと余白だけで組む**。中途半端な画像より強い
- 画像の上に文字を置くなら、**オーバーレイでコントラスト 4.5:1 を確保**する。
  背景画像は差し替えられるので、文字が読めなくなる事故が起きやすい

### 動きは控えめに

NN/g の原則5「ホームページはシンプルに」は、
**モーションとアニメーションを最小化せよ**と明記している。認知負荷とアクセシビリティの両面から。

- 自動再生カルーセルは使わない（見られず、操作されず、CLS を生む）
- スクロール連動アニメーションは1〜2箇所まで
- `prefers-reduced-motion` を必ず尊重する

## CTA

### 数を絞る

**1画面に主要CTAは1つ。** Hick の法則そのまま。
副次的な導線（資料請求、詳しく見る）は、**見た目で明確に格を下げる**。

```
[ 無料診断を申し込む ]    詳しいサービス内容を見る →
   ^^^ 塗りつぶしボタン        ^^^ テキストリンク
```

同じ見た目のボタンを2つ並べた瞬間、ユーザーは選べなくなる。

### 文言

**動詞で、具体的に、ユーザー主語で書く。**

| ✕ | ○ |
|---|---|
| 送信 | 無料診断を申し込む |
| お問い合わせ | 30分の無料相談を予約する |
| 詳細 | 料金プランを見る |
| Click Here | 導入事例を読む（3分） |

NN/g：「Click Here ではなく、情報の手がかり（information scent）の強い
説明的なリンクラベルを使う」

### 摩擦を下げる情報を添える

ボタンの直下に、**押した後の不安を消す一言**を置く。

```
[ 無料診断を申し込む ]
所要3分・費用は一切かかりません・営業のご連絡はしません
```

BtoB の CTA で止まる理由はほぼ「押したら何が起きるか分からない」。

### 配置

- **ヒーロー**（fold内）
- **中盤**（解決策や強みを読んだ直後の、納得の山）
- **最下部**（FAQ の後、全部読んだ人向け）

3箇所が基本。それ以上入れると押し売り感が出る。
**セクションごとに毎回入れない。**

### スマホの追従CTA

モバイルでは画面下部固定のCTAが有効。ただし：
- **高さを抑える**（画面を食う）
- `env(safe-area-inset-bottom)` を考慮（ホームバーに隠れる）
- fold 内では出さない（ヒーローのCTAと重複する）

### ボタンの実装

```html
<a href="#diagnosis"
   class="inline-flex items-center justify-center min-h-[48px] px-6
          rounded-lg bg-rose-deep text-white font-medium
          transition-colors duration-200
          hover:bg-rose-deep/90
          focus-visible:outline-none focus-visible:ring-2
          focus-visible:ring-rose-deep focus-visible:ring-offset-2">
  無料診断を申し込む
</a>
```

チェックポイント：
- [ ] 高さ 44px 以上（`0-core/accessibility.md`）
- [ ] hover と focus-visible の両方がある
- [ ] `transition` はプロパティを列挙（`all` ではない）
- [ ] 遷移なら `<a>`、送信なら `<button type="submit">`
- [ ] 送信中はスピナー表示。**押した瞬間に disabled にしない**
      （リクエスト開始まで有効にする。二重送信対策は開始後）
