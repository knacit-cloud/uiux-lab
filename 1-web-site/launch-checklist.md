# 公開前チェックリスト

出す直前に毎回思い出せないので、ここに置く。**上から順に通す。**

> 💡 **先に自動検査を走らせる。** 機械で判定できる項目は `snippets/js/audit.js` が拾う。
> 手作業のチェックは、それが 0 件になってから始めた方が速い。
>
> ```html
> <script src="js/audit.js" defer></script>
> ```
>
> ただし**自動検査で拾えるのは一部**。キーボード通し操作・読み上げ・
> 文章の質・情報の順序は、下のリストを人間が見るしかない。

---

## 1. 表示・レイアウト

- [ ] **320px 幅で横スクロールが出ない**（最も壊れやすい）
- [ ] 375 / 768 / 1024 / 1440px で崩れない
- [ ] ブラウザ幅を**連続的に伸縮**させても崩れない
- [ ] 200% ズームで破綻しない
- [ ] Safari / Chrome / Firefox で見た（Safari だけ挙動が違うことが多い）
- [ ] **実機のスマホで1回は見た**
- [ ] 横向き（landscape）で固定ヘッダーが画面を食いつぶさない
- [ ] ダークモードで見た（対応しているなら）
- [ ] 意図しないスクロールバーが出ていない
- [ ] 画像が全部表示される（パス切れがない）
- [ ] **長い日本語入力・空データを入れても壊れない**
- [ ] **fold 内に主要CTAが入っている**（通し試作 F-11 で追加）
      1280×900 と 375×812 の両方で確認する。目視でなく座標で測る:
      ```js
      const r = document.querySelector('.btn').getBoundingClientRect();
      ({ top: Math.round(r.top), viewport: innerHeight, inFold: r.top < innerHeight })
      ```
      ⚠️ 測る前に `scrollTo({top:0, behavior:'instant'})` で戻し、
      `scrollY === 0` を確認すること（`LESSONS.md` L-014）

## 2. 中身

- [ ] 誤字脱字（**声に出して読む**）
- [ ] 表記ゆれ（`ux-writing.md` の表記ルール）
- [ ] リンク切れがない（内部・外部とも）
- [ ] **ダミーテキスト（Lorem ipsum・「テスト」）が残っていない**
- [ ] 仮の画像・プレースホルダが残っていない
- [ ] 電話番号・メールアドレス・住所が正しい
- [ ] **個人のGmailなど、出したくない連絡先が露出していない**
- [ ] 料金・プラン内容が最新
- [ ] 背負えない表現がない（「専門家」「豊富な実績」「追加料金なし」等）
- [ ] コピーライト年が正しい

## 3. アクセシビリティ

- [ ] **キーボードだけでトップから主要導線を最後まで通せる**（Tab / Enter / Esc）
- [ ] フォーカスが常に見える。順序が視覚的順序と一致している
- [ ] **固定ヘッダーにフォーカス要素が隠れない**（`scroll-margin-top`）
- [ ] コントラスト 4.5:1（テキスト）／ 3:1（UI部品）
- [ ] すべての `<img>` に適切な `alt`（装飾は `alt=""`）
- [ ] アイコンのみのボタンに `aria-label`
- [ ] 見出しが `<h1>`〜 で階層的。`<h1>` はページに1つ
- [ ] スキップリンクがある
- [ ] フォーム部品にラベルが紐付いている
- [ ] `prefers-reduced-motion` で動きが止まる
- [ ] **`user-scalable=no` / `maximum-scale=1` がない**
- [ ] タップ領域 24×24px 以上（モバイル主体なら44×44）
- [ ] 情報を色だけで伝えていない
- [ ] `<html lang="ja">` が正しい

## 4. パフォーマンス

- [ ] **PageSpeed Insights のモバイルで LCP 2.5秒以内**
- [ ] CLS 0.1 以下
- [ ] INP 200ms 以下
- [ ] すべての `<img>` に `width` / `height`
- [ ] ヒーロー画像に `fetchpriority="high"`、`loading="lazy"` なし
- [ ] fold より下の画像に `loading="lazy"`
- [ ] 画像が WebP/AVIF で、適切なサイズにリサイズ済み
- [ ] **4000px の写真をそのまま置いていない**
- [ ] 日本語Webフォントをサブセット化、または本文はシステムフォント
- [ ] 外部ドメインに `preconnect`
- [ ] 自動再生カルーセル・巨大動画がない
- [ ] **DevTools で Slow 4G ＋ CPU 4x slowdown をかけて確認した**

## 5. フォーム（実際に送る）

- [ ] **本番環境で実際に送信して、受信を確認した**
- [ ] 自動返信メールが届く。**差出人名と本文が正しい**
- [ ] 迷惑メールに入らない（SPF / DKIM / DMARC）
- [ ] バリデーションが正しく効く（空・不正形式・長すぎる入力）
- [ ] エラー時に**入力内容が消えない**
- [ ] 送信中の表示が出る。二重送信できない
- [ ] 完了画面に「次に何が起きるか」が書いてある
- [ ] ファイル添付の上限とエラーメッセージ（該当する場合）
- [ ] CAPTCHA が本番ドメインで動く（**ホスト名設定を忘れやすい**）
- [ ] モバイルで正しいキーボードが出る（`type` / `inputmode`）
- [ ] 入力欄の font-size が 16px 以上（iOS の自動ズーム防止）
- [ ] **ペーストできる**

## 6. SEO・共有

- [ ] 全ページに固有の `<title>`（60字目安・キーワードを前に）
- [ ] 全ページに `<meta name="description">`（120字前後）
- [ ] **OGP**（`og:title` / `og:description` / `og:image` / `og:url` / `og:type`）
- [ ] **OGP画像が 1200×630px**、テキストが小さすぎない
- [ ] Twitter カード（`twitter:card` = `summary_large_image`）
- [ ] `<link rel="canonical">`
- [ ] `robots.txt`
- [ ] `sitemap.xml`
- [ ] 構造化データ（`Organization` / `FAQPage` / `BreadcrumbList`）
- [ ] favicon / apple-touch-icon
- [ ] **実際にSlackやLINEにURLを貼って、カードの見た目を確認した**
- [ ] 404 ページがある

## 7. インフラ・法務

- [ ] HTTPS で配信。HTTP からリダイレクトされる
- [ ] www あり／なしのどちらかに統一（リダイレクト）
- [ ] カスタムドメインが正しく向いている
- [ ] **プライバシーポリシー**（フォームで個人情報を扱うなら必須）
- [ ] 利用規約（必要なら）
- [ ] 特定商取引法の表記（有償サービスを直接販売するなら）
- [ ] 会社情報（所在地・代表者名・設立年）が載っている
- [ ] アクセス解析が動いている
- [ ] Search Console にサイトマップを登録した
- [ ] **環境変数・APIキーがリポジトリに入っていない**
- [ ] 公開したくないファイル（下書き・契約書テンプレ等）が配信されていない

- [ ] 本番URLで全ページを一通り開く
- [ ] フォームを**本番でもう一度**送る
- [ ] Search Console でインデックス登録をリクエスト
- [ ] PageSpeed Insights を本番URLで測る（実データは数日後）

## リリースを止めるべき条件

以下が1つでも残っていたら**公開しない**。

- フォームが本番で送信できない／通知が届かない
- 320px で横スクロールが出る
- キーボードで主要導線を通せない
- LCP がモバイルで 4秒を超える
- ダミーテキスト・プレースホルダ画像が残っている
- 個人情報を扱うのにプライバシーポリシーがない
- 出したくない連絡先やファイルが露出している
