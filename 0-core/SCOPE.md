# 0-core — 扱う範囲

## ここに入れるもの

**対象がサイトでもアプリでもモバイルでも、同じように成り立つことだけ。**

- 人間の認知の話（原則・ヒューリスティクス・法則）
- アクセシビリティの数値基準（コントラスト・タップ領域・フォーカス）
- 文字の読みやすさ（サイズ・行間・行長・日本語特有の事情）
- 色と余白の設計（トークン化・スケール）
- Web 実装レベルの共通チェックリスト

## ここに入れないもの

- **LP の構成やCTA設計** → `1-web-site/`
- **データテーブル・フィルタ・一括操作** → `2-web-app/`
- **タッチジェスチャ・OS固有の作法** → `3-mobile/`
- 特定のフレームワーク／ライブラリの使い方
- ビジュアルの流行（グラスモーフィズム等のスタイル論）

## 判断基準

「これは管理画面でも LP でも同じか？」と自問する。
片方でしか成り立たないなら、core ではなく対象フォルダに置く。

**core が太ると混在が始まる。薄く保つことが core の仕事。**
