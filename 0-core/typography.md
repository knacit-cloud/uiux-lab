# タイポグラフィ — 日本語を含む

**日本語サイトの参考資料の大半は英語圏由来で、そのまま使うと日本語で破綻する。**
ここは日本語の事情を含めて書く。この資料で一番差が出る部分。

---

## 数値の基準（デジタル庁デザインシステム準拠）

⚠️ 出典：[デジタル庁デザインシステム β版 — Typography](https://design.digital.go.jp/dads/foundations/typography/)（本文照合済 / v2系）
公的機関の日本語UIとして根拠を示せる、数少ない日本語の一次資料。

### フォントサイズ

| 用途 | サイズ |
|---|---|
| 大見出し・数値の強調表示 | 48–64px |
| 見出し〜本文 | 16–45px |
| **本文の下限** | **16px** |
| 限定用途（フッター、狭いUI領域） | 14px |
| 14px 未満 | **使わない** |

**本文 16px は下限であって、推奨値ではない。**
読み物性の高いページ（記事・LP本文）は 17–18px の方が読みやすい。

### 行間（line-height）

| 文脈 | 値 |
|---|---|
| 1行で完結するUI部品（ボタン等） | 100% |
| 情報密度の高い画面（管理画面） | 120–130% |
| 見出し | 140% |
| **一般的な本文（下限）** | **150%** |
| 読み物本文・心理的負荷を下げたい場合 | 160–175% |

原典の表現：「読み物コンテンツにおける本文テキストの行ボックスの高さ（行高）は
フォントサイズに対して**少なくとも1.5倍**を維持することを推奨します」

**実務の既定値：本文 `line-height: 1.7`、見出し `1.4`。**
日本語は文字が正方形に近く字面率が高いため、欧文と同じ行間だと詰まって見える。
欧文向けテンプレートの `1.5` をそのまま使うと日本語では窮屈。

### 字間（letter-spacing）

| サイズ | 値 |
|---|---|
| 45px 以上 | 0 |
| 36px 前後 | 0.01em（1%） |
| 26px 以下 | 0.02em（2%） |

大きい文字ほど字間を詰め、小さい文字ほど開ける。逆をやると読みにくくなる。

### ウェイト

デジタル庁は **400（Normal）と 700（Bold）の2段階**に絞っている。
中間ウェイトを増やすと一貫性が壊れやすく、Webフォントの読み込みコストも増える。
**迷ったら 400 / 700 の2つで組む。**

## 行長（1行の文字数）

| 言語 | 適正 |
|---|---|
| 日本語 | **35–45字** |
| 欧文 | **45–75字** |

長すぎると次の行の頭を見失う。短すぎると視線の折り返しが増えて疲れる。

```css
/* 日本語本文の実装 */
.prose { max-width: 40em; }   /* em は font-size 基準なので拡大時も維持される */
```

`max-width` を px で固定すると、ユーザーが文字を拡大したとき行長が伸びてしまう。**em / ch を使う。**

## 日本語特有の注意

### イタリックを使わない
日本語フォントに真のイタリック字形はない。ブラウザは通常字形を機械的に傾ける（合成斜体）だけで、
著しく可読性が落ちる。強調は**太字か色**で行う。
⚠️ デジタル庁も明示的に非推奨としている（上記出典）。

### 和欧混植
日本語文中の英数字は、日本語フォントの従属欧文より専用欧文フォントの方が美しい。
`font-family` は **欧文フォントを先に、日本語フォントを後に**書く。

```css
font-family: "Inter", "Zen Kaku Gothic New", sans-serif;
/* Inter が欧文を、Zen Kaku Gothic New が日本語を担当する */
```

順序が逆だと、日本語フォントの従属欧文が使われてしまう。

### 禁則処理と折り返し
```css
p {
  line-break: strict;          /* 日本語の禁則を厳格に */
  overflow-wrap: anywhere;     /* 長いURL等がはみ出すのを防ぐ */
  word-break: normal;          /* normal を明示。break-all は日本語を壊す */
}
```

`word-break: break-all` は日本語では**単語の途中で無造作に改行される**ため避ける。

### 見出しの改行位置
日本語の見出しは、意味の切れ目で改行されないと読みにくい。

```css
h1, h2, h3 { text-wrap: balance; }   /* 行の長さを均等化 */
p          { text-wrap: pretty; }    /* 最終行の孤立語を防ぐ */
```

より厳密に制御したい見出しは、`<wbr>` や `<span style="display:inline-block">` で
意味の塊を明示する。

### ルビ
`<ruby>` のサイズは、ブラウザ既定で親文字の50%。小さすぎる場合が多いので調整する。

## タイプスケール

サイズをその場のノリで決めない。**比率で決める。**

実用的な比率は **1.25（Major Third）** 前後。

| 役割 | サイズ（16px基準・1.25比） |
|---|---|
| Display | 48–61px |
| H1 | 39px |
| H2 | 31px |
| H3 | 25px |
| H4 | 20px |
| Body | 16px |
| Small | 14px |

**画面幅で見出しだけ縮める。** モバイルで 48px の見出しは画面を食いつぶす。

```css
h1 { font-size: clamp(1.75rem, 5vw, 3rem); }
```

本文サイズは `clamp` で縮めない。**16px を下回らせない。**

## その他の作法

⚠️ 出典：[Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines)（本文照合済）

- 三点リーダは `…`（U+2026）。`...` と書かない
- 引用符は `“ ”`。`" "` を使わない
- 数字と単位の間はノーブレークスペース：`10&nbsp;MB`、`⌘&nbsp;K`
- 読み込み中の文言は `…` で終える：「送信中…」
- **数値を縦に並べる列には `font-variant-numeric: tabular-nums`**
  （等幅数字。桁が揃わないと比較できない）
- 数量は算用数字で書く
