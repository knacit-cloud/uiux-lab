## 実測が想定を否定したこと

### ① 「洗練＝角丸が大きい」は成立しなかった

角丸の最頻値は **2px 〜 60px** と極端にばらけた。

| サイト | 角丸 |
|---|---|
| linear.app | **2px**（ほぼ角がある） |
| stripe.com | 4px |
| smarthr.jp | 8px |
| kaminashi.jp | **60px**（強い丸み） |

**「現代の洗練されたサイト」として真っ先に挙がる Linear が、最も角ばっている。**

→ 角丸の大きさに**現代の合意は存在しない**。
「角がない＝洗練」は思い込みだった可能性が高い。
むしろ**題材と業種で決まる**（`visual-design.md §0` の「題材の世界から引く」と整合的）。

### ② 日本語サイトの行間は、資料が推奨する 1.7 より狭い

| | 行間 |
|---|---|
| **本資料の推奨** | **1.7** |
| smarthr.jp | 1.5 |
| stripe.com(ja) | 1.4 |
| kaminashi.jp | 1.4 |

**ただし「実例が正しい」わけではない。**
デジタル庁デザインシステムは本文 **1.5 以上**を推奨しており、
stripe(ja) と kaminashi の **1.4 は基準未満**。

→ 基準（1.5+）と実例（1.4〜1.5）が食い違っている領域。
資料の 1.7 は**基準側に寄りすぎ**の可能性はあるが、下げる根拠にはならない。
**n=5 では判断しない。** 保留。

### ③ 自作の見本帳は「短く・薄い」

| | 自作 | 実例の範囲 |
|---|---|---|
| ページ長 | **7画面** | 11.7〜16.4 |
| 密度 | **223字/画面** | 244〜561 |
| ボタン数 | 7 | 3〜47 |
| 画像数 | **0** | 19〜156 |

**実例はどれも自作の1.7〜2.3倍の長さがある。**
「余白を広く」を守った結果、**情報量が足りていない**可能性。

→ ただし自作はデモページであり実サイトではないので、直接比較はできない。
`process.md` で通しで1本作ったときに再測定して判断する。

### ④ 日本のサイトはボタンと画像が圧倒的に多い

| | ボタン | 画像 |
|---|---|---|
| linear.app（海外） | **3** | 28 |
| stripe.com(ja) | 22 | 19 |
| smarthr.jp | 42 | 85 |
| kaminashi.jp | **47** | **156** |

海外SaaSは導線を極端に絞り、日本のBtoBは網羅的に並べる。
**どちらが良いかはここでは判定できない**が、
**海外SaaSだけを基準にすると日本のBtoBでは的を外す**ことは言える。

→ 日本語サイトを測る意味があった（当初の判断は正しかった）。

### ⑤ 本文16pxは実測でも支持された

5本中4本が 16px。kaminashi のみ 14px。
→ 資料の「本文16px下限」は**維持してよい**。

## 測定ツールの限界（今回判明した分）

| # | 限界 | 影響 |
|---|---|---|
| 1 | **セクション余白を `padding` でしか測っていない** | stripe / kaminashi は測定不可（margin や内側ラッパーで作っている） |
| 2 | **出現アニメ前に測ると要素を取りこぼす** | 対策済み（測定前にスクロールして発火させる）。自作ページで 6→9 の差が出て発覚 |
| 3 | h1 のサイズが不正確な場合がある | smarthr で h1=16px。ロゴを h1 にしている等、DOM構造依存 |
| 4 | 1画面の定義がビューポート依存 | 1280×900 固定で測っているが、他の幅では変わる |
| 5 | **HTTPS ページから HTTP localhost の script を読めない** | 混在コンテンツでブロック。スクリプトを直接貼る必要がある |

## この調査の使い方（重要）

**分布は「よくあるもの」を示すだけで、「良いもの」は示さない。**
中央値に寄せると平均的なものが出来上がる（`LESSONS.md` L-007）。

正しい使い方：

- **自分がどこにいるか把握する**
- **外れているのが意図か事故かを区別する**
- **大半の軸は範囲内に収め、1つの軸だけ意図して外す**（＝シグネチャー）

今回の最大の収穫は数値そのものではなく、
**「角丸が大きい＝洗練」という思い込みが実測で否定されたこと。**
